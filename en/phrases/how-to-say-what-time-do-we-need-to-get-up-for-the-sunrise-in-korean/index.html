How to say "What time do we need to get up for the sunrise?" in Korean (해돋이 보러 몇 시에 일어나야 돼요?)

You can say this

해돋이 보러 몇 시에 일어나야 돼요?

haedoji boreo myeot sie ireonaya dwaeyo

Meaning: What time do we need to get up for the sunrise?
