How to say "I'll run the dryer for twenty minutes" in Korean (건조기 이십 분 돌릴게요)

You can say this

건조기 이십 분 돌릴게요.

geonjogi isip bun dollilgeyo

Meaning: I'll run the dryer for twenty minutes.
