How to say "You explained it so well that I found it right away" in Korean (설명을 잘해 줘서 금방 찾았어요)

You can say this

설명을 잘해 줘서 금방 찾았어요.

seolmyeongeul jalhae jwoseo geumbang chajasseoyo

Meaning: You explained it so well that I found it right away.
