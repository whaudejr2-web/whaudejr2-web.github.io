How to say "The return station is full" in Korean (대여소가 꽉 찼어요)

You can say this

대여소가 꽉 찼어요.

daeyeosoga kkwak chasseoyo

Meaning: The return station is full.

Good to know

You can return a Ttareungyi at any station. If every rack is taken, use the cable lock to attach your bike to another parked Ttareungyi and the return still registers.
