How to say "The front door code is 1234" in Korean (공동 현관 비밀번호는 일이삼사예요)

You can say this

공동 현관 비밀번호는 일이삼사예요.

gongdong hyeongwan bimilbeonhoneun il i sam sayeyo

Meaning: The front door code is 1234.

Good to know

Most apartment buildings have a locked shared entrance with a keypad, so the rider cannot reach your door without the code. Delivery apps have a separate field for it right next to the address.
