How to say "What's the door code?" in Korean (현관 비밀번호가 뭐예요?)

You can say this

현관 비밀번호가 뭐예요?

hyeongwan bimilbeonhoga mwoyeyo

Meaning: What's the door code?

Good to know

Almost every home and guesthouse in Korea uses a keypad lock instead of a metal key. You type the code and press the star or pound key, and the door beeps and locks itself behind you when it closes.
