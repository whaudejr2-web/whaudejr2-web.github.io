Como se diz "Um, dois, três. Estes são os números para contar coisas e pessoas" em coreano (하나, 둘, 셋)

Você pode dizer isto

하나, 둘, 셋.

hana, dul, set

Significado: Um, dois, três. Estes são os números para contar coisas e pessoas.

Bom saber

O coreano tem dois sistemas de números. Estes números nativos contam coisas, pessoas, horas e a idade. Outro sistema, vindo do chinês, é usado para dinheiro, datas, telefones, linhas de ônibus e andares.
