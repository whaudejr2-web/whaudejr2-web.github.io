Como se diz "Com licença, este ônibus vai para Namsan?" em coreano (기사님, 이 버스 남산 가요?)

Você pode dizer isto

기사님, 이 버스 남산 가요?

gisanim, i beoseu namsan gayo

Significado: Com licença, este ônibus vai para Namsan?

Bom saber

Os ônibus de Seul são identificados por cor. Os azuis fazem rotas longas pela cidade, os verdes cobrem rotas locais mais curtas e os vermelhos vão para as cidades vizinhas.
