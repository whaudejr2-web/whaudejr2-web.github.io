Como se diz "Só dá para pedir a partir de duas porções" em coreano (이 인분부터 주문 가능해요)

Você pode dizer isto

이 인분부터 주문 가능해요.

i inbunbuteo jumun ganeunghaeyo

Significado: Só dá para pedir a partir de duas porções.

Bom saber

A maioria dos restaurantes de churrasco coreano exige no mínimo duas porções de carne, então quem vai sozinho pode ser recusado ou ter que pedir duas. Alguns lugares novos têm grelhas individuais.
