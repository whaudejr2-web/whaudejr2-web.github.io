Como se diz "Este é um assento preferencial?" em coreano (여기 노약자석이에요?)

Você pode dizer isto

여기 노약자석이에요?

yeogi noyakjaseogieyo

Significado: Este é um assento preferencial?

Bom saber

Os assentos preferenciais ficam nas duas pontas de cada vagão. A maioria dos passageiros em Seul os deixa vazios mesmo com o trem lotado, e os assentos cor-de-rosa são para gestantes.
