Cómo se dice "El domingo ya tengo un compromiso" en coreano (일요일은 약속이 있어요)

Puedes decir esto

일요일은 약속이 있어요.

iryoireun yaksogi isseoyo

Significado: El domingo ya tengo un compromiso.

Dato útil

La palabra coreana que se usa aquí significa promesa y también cita, así que tener planes es literalmente tener una promesa. Se usa para todo, desde una cena hasta una cita con el dentista.
