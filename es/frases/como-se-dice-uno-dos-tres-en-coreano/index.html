Cómo se dice "Uno, dos, tres" en coreano (하나, 둘, 셋)

Puedes decir esto

하나, 둘, 셋.

hana, dul, set

Significado: Uno, dos, tres.

Dato útil

El coreano tiene dos sistemas de números. Estos números nativos se usan para contar cosas, personas y tu edad, mientras que otro sistema de origen chino se usa para precios, fechas y teléfonos.
