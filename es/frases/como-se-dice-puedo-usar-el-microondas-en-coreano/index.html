Cómo se dice "¿Puedo usar el microondas?" en coreano (전자레인지 써도 돼요?)

Puedes decir esto

전자레인지 써도 돼요?

jeonjareinji sseodo dwaeyo

Significado: ¿Puedo usar el microondas?

Dato útil

Casi todas las tiendas tienen un microondas gratis y un dispensador de agua caliente para los clientes, y la mayoría tiene una pequeña barra donde puedes comer ahí mismo.
