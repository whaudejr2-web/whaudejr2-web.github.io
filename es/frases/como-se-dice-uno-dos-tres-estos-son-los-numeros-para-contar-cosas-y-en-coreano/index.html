Cómo se dice "Uno, dos, tres. Estos son los números para contar cosas y personas" en coreano (하나, 둘, 셋)

Puedes decir esto

하나, 둘, 셋.

hana, dul, set

Significado: Uno, dos, tres. Estos son los números para contar cosas y personas.

Dato útil

El coreano tiene dos sistemas de números. Estos números nativos cuentan cosas, personas, horas y la edad. Otro sistema tomado del chino se usa para dinero, fechas, teléfonos, rutas de autobús y pisos.
