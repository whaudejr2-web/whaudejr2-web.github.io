Cómo se dice "Tarda como una hora" en coreano (한 시간쯤 걸려요)

Puedes decir esto

한 시간쯤 걸려요.

han siganjjeum geollyeoyo

Significado: Tarda como una hora.

Dato útil

El coreano tiene una palabra para la hora del reloj y otra distinta para una hora de duración. Ambas usan números nativos, así que una hora y la una empiezan con el mismo número.
